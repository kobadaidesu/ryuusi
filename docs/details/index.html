パラメーター詳細

Tab キーを押して設定パネルを開き、各項目を調整できます。

🎨 Color Presets（色）

パラメーター 内容
Hue min / max 粒子の色相範囲（0〜1 = 虹の全域）。min=max で単色、範囲を広げるとグラデーション。
プリセットボタン群 Fire / Gold / Aurora / Rainbow など 16 種の色を即適用。
Recolor now 既存粒子の色を現在の色相設定で塗り直す。

📐 Sim Area（壁・プレイエリア）

パラメーター 内容
Width / Height px 粒子が跳ね返る壁の範囲。0 = ウィンドウ全体（壁なし）。
Bounce 壁に当たったときの反発係数。0 = 吸収、1 = 完全反射。

🧲 Attract / Repel（引力・斥力）

パラメーター 操作 内容
Attract str 左クリック 引力の強さ。大きいほど強く引き寄せる。
Attract range 左クリック 引力の有効距離（px）。0 = 無制限。
Repel str 右クリック 斥力の強さ。大きいほど強く弾く。
Passive attract 常時 マウスカーソルへの常時引力。0 で無効。
Gather speed G キー G キー押し中の収束速度。

⏸ Time Stop（T キー）

パラメーター 内容
TS Attract タイムストップ中にカーソルへ引き寄せる力。
TS Damping タイムストップ中の速度減衰率。小さいほど急激に止まる（0.1〜0.99）。

🌀 Vortex / Explode（V・E キー）

パラメーター 内容
Vortex str 渦の回転力。大きいほど速く渦巻く。
Vortex cap 渦の力の上限。大きすぎると粒子が飛散するのを防ぐ。
Explode str 爆発の押し出し力。
Explode cap 爆発力の上限。

🔵 Ripple（B キー）

パラメーター 内容
Ripple str 波紋が粒子を弾く衝撃力。

⚙️ Physics（物理全般）

パラメーター 内容
Gravity 重力（下向き）。正 = 落下、負 = 浮上、0 = 無重力。
Damping 速度の減衰率（毎フレーム）。0.999 = ほぼ減衰なし、0.90 = すぐ止まる。
Speed limit 粒子の最大速度（px/秒）。上限を下げると動きが穏やかになる。
Bounce 壁反発係数（Sim Area と共通）。

🔴 Particle of number（粒子数・サイズ）

パラメーター 内容
Count 表示する粒子の上限数（最大 300,000）。
Point size 粒子 1 個の描画サイズ（px）。大きくすると粒が目立つ。
